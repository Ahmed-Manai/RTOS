# RTOS: FreeRTOS tasks on an STM32F407

Two FreeRTOS tasks on an STM32F407 (STM32F4-Discovery board) that take turns with binary semaphores. Each task blinks its own LED and writes its name on a 16x2 character LCD, so you can watch the scheduling happen.

The project was generated with STM32CubeMX (CMSIS-RTOS v2 on top of FreeRTOS) and built with Keil MDK-ARM.

## How it works

| Task | LED | What it does |
|------|-----|--------------|
| `myTask01` (`Task1`) | PD12 | Waits for `myBinarySem01`, blinks for 500 ms, prints "Task 1" on both LCD lines, then gives `myBinarySem02` |
| `myTask02` (`Task02`) | PD13 | Waits for `myBinarySem02`, blinks for 200 ms, prints "Task 2" on both LCD lines, then gives `myBinarySem01` |

The two binary semaphores hand control back and forth, so the tasks never write to the LCD at the same time. A mutex (`myMutex01`) is also configured; the code keeps the mutex version commented out for comparison.

## LCD wiring (4-bit mode)

| LCD pin | MCU pin |
|---------|---------|
| RS | PB12 |
| E | PB13 |
| D4 | PD8 |
| D5 | PD9 |
| D6 | PD10 |
| D7 | PD11 |

The driver in `STM_MY_LCD16X2.c` supports 4-bit and 8-bit modes and uses a hardware timer for the microsecond delays the LCD needs.

## Project layout

```text
RTOS_LED.ioc           STM32CubeMX configuration (pins, FreeRTOS tasks, semaphores)
Core/Src/main.c        task functions, semaphores and LCD start-up
STM_MY_LCD16X2.c/.h    HD44780 16x2 LCD driver
Drivers/, Middlewares/ STM32 HAL and FreeRTOS sources generated by CubeMX
MDK-ARM/               Keil uVision project
```

## Build and flash

1. Open `MDK-ARM/RTOS_LED.uvprojx` in Keil uVision 5, or regenerate the project for STM32CubeIDE from `RTOS_LED.ioc`.
2. Build and flash the board over ST-LINK.
3. Connect the LCD as in the table above and reset the board.
